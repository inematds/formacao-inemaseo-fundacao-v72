Aula 5 · 15 min

Sitemaps com data real e hreflang

O sitemap é a lista de páginas que você entrega ao buscador. Ele só ajuda se disser a verdade: as páginas que existem e a data em que cada uma mudou de fato. Se o site tem versões em outros idiomas, o hreflang diz qual é qual, e isso abre um mercado inteiro.

Começar a aula

Nesta aula você vai

  1. 1Por que o sitemap sai do mesmo dado que gera as páginas
  2. 2Data real de mudança, nunca a hora do build
  3. 3hreflang de ida e volta, em cada página
  4. 4O caso da página em espanhol do INEMA

Objetivo: gerar o sitemap do mesmo dado das páginas, com data real de mudança e hreflang recíproco quando houver tradução.

01 · Um dado, duas saídas

Clique em cada bloco.

Clique em cada bloco do diagrama para ver o que ele faz.

Sitemap escrito à mão envelhece no primeiro dia. Sitemap gerado do dado não mente.

02 · Montar e conferir

Clique em cada etapa.

1. Achar o gerador

Muitas plataformas de site geram o sitemap sozinhas. Descubra onde ele é gerado e de que dado sai.

Se o sitemap foi escrito à mão, ele é a primeira coisa a trocar.

2. Data real

Abra o sitemap e olhe três URLs. A data bate com a última mudança de verdade daquela página?

Se todas as datas são de hoje, o gerador está usando a hora do build.

No portal do INEMAO gerador pega a data do catálogo, com o comentário "nunca use a hora do build" no código.

3. hreflang

Para cada página traduzida: a versão PT aponta para EN e ES, e cada uma aponta de volta. Inclua o x-default.

Pode ir no HTML de cada página ou no sitemap. O raio-x mostra os dois: a linha hreflang da página e a contagem no sitemap.

4. Por que vale

Em espanhol a concorrência costuma ser menor. Traduza só o texto; estrutura, imagens e código são reaproveitados.

No INEMAA página /es/aprender-inteligencia-artificial/ foi indexada em 03/10/2026. Na semana seguinte já tinha de 5 a 10 impressões em cada consulta em espanhol, nas posições 29 a 61.

03 · Como fica e como conferir

O formato do sitemap com hreflang, o padrão do gerador e o comando de conferência.

sitemap.xml · uma URL com tradução
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9" xmlns:xhtml="http://www.w3.org/1999/xhtml">
<url>
<loc>https://www.seusite.com/</loc>
<xhtml:link rel="alternate" hreflang="pt-BR" href="https://www.seusite.com/" />
<xhtml:link rel="alternate" hreflang="en" href="https://www.seusite.com/en/" />
<xhtml:link rel="alternate" hreflang="es" href="https://www.seusite.com/es/" />
<xhtml:link rel="alternate" hreflang="x-default" href="https://www.seusite.com/" />
<lastmod><aaaa-mm-dd da última mudança></lastmod>
</url>
</urlset>
Next.js · app/sitemap.ts (padrão do portal, resumido)
// a data vem do dado; nunca a hora do build
const languages = { 'pt-BR': `${SITE_URL}/`, en: `${SITE_URL}/en/`, es: `${SITE_URL}/es/`, 'x-default': `${SITE_URL}/` }
return ['/', '/en/', '/es/'].map(path => ({
  url: `${SITE_URL}${path}`,
  lastModified: latest,
  alternates: { languages },
}))
Terminal · URLs e hreflang do sitemap
x=$(curl -4 -m 20 -s https://www.seusite.com/sitemap.xml)
echo "$(echo "$x" | grep -c '<loc>') URLs, $(echo "$x" | grep -c 'hreflang') anotações hreflang"
echo "$x" | grep -oE '<lastmod>[^<]*' | sort | uniq -c | sort -rn | head
Exemplo do repositório

Primeira URL do sitemap de www.inema.club em 19/10/2026:

<loc>https://www.inema.club/</loc>
<xhtml:link rel="alternate" hreflang="pt-BR" href="https://www.inema.club/" />
<xhtml:link rel="alternate" hreflang="en" href="https://www.inema.club/en/" />
<xhtml:link rel="alternate" hreflang="es" href="https://www.inema.club/es/" />
<xhtml:link rel="alternate" hreflang="x-default" href="https://www.inema.club/" />
<lastmod>2026-10-19</lastmod>

A home muda quando o catálogo muda; por isso a data é a do catálogo.

  • Todas as datas iguais na última linha do comando: provável hora do build.
  • 0 anotações hreflang num sitemap: normal se aquelas páginas não têm tradução; problema se têm.
  • Mais URLs no sitemap que páginas no site: o sitemap não sai do dado.

04 · Prática: um sitemap que diz a verdade

Use os blocos de Sitemaps do seu raio-x.txt.

E1 · Três datas

20 min

Escolha 3 URLs do seu sitemap e compare o lastmod com a data da última mudança real de cada página.

Pronto quando: as 3 datas batem, ou você anotou de onde o gerador tira a data e o que mudar.

E2 · Ida e volta do hreflang

20 min

Se o site tem tradução, abra uma página em cada idioma e confira se cada uma lista todas as versões. Sem tradução, anote "não se aplica" e o idioma que faria sentido.

Pronto quando: a ida e a volta foram conferidas nas versões, ou o "não se aplica" está anotado com o motivo.
