Aula 2 · 16 min

Raio-x só de leitura: o HTML que o servidor entrega

O buscador não vê o seu site como você vê no navegador: ele lê o HTML que o servidor entrega, quase sempre sem rodar JavaScript. Um script de 40 linhas faz essa leitura por você, sem mudar nada no site, e mostra em minutos o que nenhum painel bonito mostra.

Começar a aula

Nesta aula você vai

  1. 1Baixar o método inemaSEO e rodar a auditoria
  2. 2Ler redirecionamentos, robots.txt, sitemaps e páginas
  3. 3Achar página sem link interno no HTML
  4. 4Transformar a saída em uma lista de achados

Objetivo: rodar o auditoria.sh no seu site e ler cada linha da saída como o buscador lê.

01 · O que o raio-x olha

Só leitura: o script usa curl e não altera nada. Clique em cada bloco.

Clique em cada bloco do diagrama para ver o que ele faz.

Rodou, salvou, leu. Nada muda no site; o raio-x é o retrato antes de mexer.

02 · Do download à lista de achados

Clique em cada etapa.

1. Baixar

O inemaSEO é público, com licença MIT. Você precisa de um terminal com bash e curl: Mac e Linux já têm; no Windows, use o WSL ou o Git Bash.

Clone o repositório e entre na pasta.

Onde estágithub.com/inematds/inemaseo-metodo, pasta tools/.

2. Rodar

Passe o endereço principal e os caminhos das páginas, separados por espaço. Salve a saída num arquivo para comparar depois.

Leva menos de um minuto num site pequeno.

DicaEscolha uma página de produto ou serviço e uma página nova, que você ainda não viu no Google.

3. Ler

Canônico vazio ou diferente do endereço? Links internos perto de zero? Meta robots com noindex numa página importante? Cada um vira um achado.

Não corrija nada ainda: só anote.

Achado típicoPágina de catálogo que virou "só busca" no navegador e deixou centenas de páginas sem nenhum link no HTML.

4. Anotar

Para cada achado, copie a linha da saída que o mostra e a aula deste curso que trata dele.

Essa lista é o seu plano das próximas semanas.

03 · Os comandos do raio-x

Copie e rode no terminal. Troque o endereço pelo do seu site.

Terminal · baixar o método
git clone https://github.com/inematds/inemaseo-metodo.git
cd inemaseo-metodo
Terminal · rodar e salvar
bash tools/auditoria.sh https://www.seusite.com /pagina-1/ /pagina-2/ > raio-x.txt
cat raio-x.txt

Em 30/09/2026 (commit bc50d11), a página /cursos/ virou "só busca" e as 310 fichas perderam o único link interno que vinha no HTML do servidor. Na tela parecia tudo certo.

A correção (8229495) foi um índice recolhido em <details> com todos os links, sem mudança visual. A linha "links internos no HTML" da /cursos/, acima, é o retrato depois da correção.

  • Olhar só no navegador: o que o JavaScript monta pode não existir para o robô.
  • Auditar só a home: o problema costuma estar na página de catálogo ou na nova.
  • Corrigir antes de anotar: sem o retrato de antes, você não sabe se melhorou.

04 · Prática: o seu raio-x

Guarde o raio-x.txt: as aulas 4 a 8 comparam com ele.

E1 · Rodar e salvar

20 min

Rode a auditoria na home e em 2 páginas do seu site e salve em raio-x.txt.

Pronto quando: o arquivo existe e tem os blocos Redirecionamentos, robots.txt, Sitemaps e Páginas.

E2 · Três achados

20 min

Leia a saída e preencha a lista de achados com pelo menos 3 linhas (se estiver tudo certo, anote o que conferiu).

Pronto quando: cada achado tem a linha da saída copiada e a aula que trata dele.
